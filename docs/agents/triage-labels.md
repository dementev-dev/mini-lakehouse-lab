# Метки триажа

Навыки используют пять стандартных ролей триажа. Таблица связывает эти роли с
метками трекера данного репозитория.

| Роль в mattpocock/skills | Метка в нашем трекере | Значение |
| ------------------------ | --------------------- | -------- |
| `needs-triage` | `needs-triage` | Сопровождающий должен оценить задачу |
| `needs-info` | `needs-info` | Для продолжения нужен ответ автора |
| `ready-for-agent` | `ready-for-agent` | Задача полностью описана и готова для автономного агента |
| `ready-for-human` | `ready-for-human` | Задачу должен выполнить человек |
| `wontfix` | `wontfix` | Задача не будет выполняться |

Когда навык упоминает роль, используй соответствующую метку из этой таблицы.

Если набор меток репозитория изменится, обнови правый столбец.
