# Трекер задач: Gitea

Задачи и спецификации этого репозитория хранятся в Gitea Issues:
`git.dementev.space/ddmitry/mini-lakehouse-lab`. Для работы с ними используй
CLI `tea`.

## Основные команды

- **Создать задачу**:
  `tea issues create --title "..." --description "..."`
- **Прочитать задачу вместе с комментариями**:
  `tea issues <номер> --comments --output yaml`
- **Получить список задач**:
  `tea issues list --state open --output json`; при необходимости добавь
  фильтры, например `--labels`
- **Добавить комментарий**:
  `tea comments add <номер> --description "..."`
- **Добавить или удалить метки**:
  `tea issues edit <номер> --add-labels "..."` или
  `tea issues edit <номер> --remove-labels "..."`
- **Назначить исполнителя**:
  `tea issues edit <номер> --add-assignees "<имя пользователя>"`
- **Закрыть задачу**: сначала опубликуй итоговый комментарий через
  `tea comments add`, затем выполни `tea issues close <номер>`

Запускай команды из каталога репозитория: `tea` определит Gitea-подключение и
репозиторий по Git remote.

## Pull request как источник задач для триажа

**Обрабатывать pull request как входящие задачи: нет.**

Измени значение на `да`, если в будущем репозиторий начнёт рассматривать
внешние pull request как запросы на изменение. Навык `/triage` читает эту
настройку.

## Когда навык просит опубликовать задачу в трекере

Создай Gitea Issue с помощью `tea issues create`.

## Когда навык просит получить связанную задачу

Выполни `tea issues <номер> --comments --output yaml`.

## Операции Wayfinder

Навык `/wayfinder` использует одну задачу-карту и связанные с ней дочерние
задачи.

- **Карта**: задача с меткой `wayfinder:map`, содержащая разделы Notes,
  Decisions-so-far и Fog
- **Дочерняя задача**: задача, описание которой начинается со строки
  `Part of #<номер карты>` и содержит метку типа `wayfinder:<тип>`:
  `research`, `prototype`, `grilling` или `task`
- **Блокировка**: строка `Blocked by: #<номер>, #<номер>` в начале описания;
  задача разблокирована, когда закрыты все перечисленные задачи
- **Фронтир**: найди открытые дочерние задачи карты, исключи назначенные и
  заблокированные, затем выбери первую по порядку в карте
- **Взять в работу**: назначь исполнителя командой
  `tea issues edit <номер> --add-assignees "<имя пользователя>"`; это первая
  запись в трекер в рамках сессии
- **Завершить**: опубликуй ответ в комментарии, закрой дочернюю задачу и добавь
  в раздел Decisions-so-far карты ссылку на сохранённый контекст
